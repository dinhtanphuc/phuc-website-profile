BUG-101 Severity: Major Priority: High Open

Order total is not recalculated after removing a promo code at checkout

Environment
Staging · Chrome 130 · Windows 11
Build
2.14.0-rc2
Found in
Sprint 14 regression

Steps to reproduce

  1. Add any product to the cart and open checkout.
  2. Apply promo code SPRING10; the total drops by 10%.
  3. Click Remove next to the promo code.

Expected

The promo line disappears and the total returns to the original amount.

Actual

The promo line disappears but the total keeps the discounted amount until the page is reloaded.

Attachments: screen recording, network log (HAR). Suspected cause: totals are only recalculated on apply, not on remove.
